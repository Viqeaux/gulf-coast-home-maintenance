Subscribe, don't download

A subscription keeps updating as the calendar improves. A downloaded file is a snapshot — it never changes again, and duplicates pile up if you import twice.

Google Calendar on a phone

The Google Calendar app can't add a subscription itself. Do it once from a browser — phone or computer — and it shows up on every device signed into that account.

  1. Tap Add to Google Calendar above.
  2. Confirm Add when Google asks.
  3. In the app, open the menu and switch the new calendar on.

Google refreshes subscribed calendars slowly — sometimes up to a day. Nothing here is urgent to the hour, so it doesn't matter.
